Atividade DOM

Parte 1 — Pesquisa

1. O que é DOM?
É o Document Object Model. É uma interface que transforma o código HTML estático em uma estrutura de objetos que o JavaScript consegue "ler" e alterar em tempo real. Sem o DOM, o JavaScript não conseguiria mexer na página.
2. O que é um nó (node)?
No DOM, a página é uma árvore e cada parte dela é um nó. Elementos: São as tags (ex: h1, div). Atributos: São as propriedades das tags (ex: class, src). Textos: É o conteúdo escrito dentro das tags.
3. Métodos: getElementById(), querySelector(), querySelectorAll()
getElementById(): Pega um único elemento pelo seu ID único.
querySelector(): Pega o primeiro elemento que encontrar usando seletores CSS.
querySelectorAll(): Pega todos os elementos que combinam com o seletor e coloca em uma lista.
4. Diferença entre innerHTML e innerText
innerText: Foca apenas no texto. Se você colocar uma tag HTML lá, ela aparece escrita como texto comum.
innerHTML: Foca no conteúdo HTML. Ele interpreta as tags (por exemplo, consegue criar um link ou colocar um texto em negrito).
5. O que são eventos?
São ações detectadas pelo navegador que geram uma resposta do código. onclick: Quando o usuário clica.
onchange: Quando o valor de um campo muda (comum em formulários).
onmouseover: Quando o mouse passa por cima de um elemento.
